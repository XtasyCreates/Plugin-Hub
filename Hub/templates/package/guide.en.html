Install

  1. Unblock the ZIP before you extract it: right-click the ZIP file → Properties → tick Unblock at the bottom → OK. Otherwise Windows blocks the plug-in.
  2. Extract the folder to a permanent place, for example Documents\Rhino Plug-ins\{product}. Rhino loads the plug-in from there – do not move the folder afterwards.
  3. Start Rhino and drag the file {rhp} into the Rhino window. Rhino installs the plug-in and loads it every time it starts.

Activate

  1. Run the command {command} in Rhino. The activation window opens and shows your device ID.
  2. Send the device ID to {contact} – the easiest way is the Request a code button, which prepares the mail for you.
  3. You receive an activation code. Paste it under "2)" and click Activate.

A trial code works until a set day. From seven days before, Rhino reminds you in its command line. You can enter a new code at any time with the command {activationCommand}.

Update

  1. Close Rhino.
  2. Replace the files in the plug-in folder with the new ones (unblock the new ZIP first, too).
  3. Start Rhino – the activation stays in place.

New computer

An activation code belongs to one computer. On a new computer, or after reinstalling Windows, the activation window shows a new device ID. Send it to {contact} and you will get a new code.
