Version {version} · {date} · Plugin für Rhino 8 unter Windows

Installieren

  1. ZIP entsperren, bevor du es entpackst: Rechtsklick auf die ZIP-Datei → Eigenschaften → unten Zulassen anhaken → OK. Sonst blockiert Windows das Plugin.
  2. Entpacke den Ordner an einen festen Platz, zum Beispiel Dokumente\Rhino Plug-ins\{product}. Rhino lädt das Plugin von dort – verschiebe den Ordner danach nicht mehr.
  3. Starte Rhino und ziehe die Datei {rhp} in das Rhino-Fenster. Rhino installiert das Plugin und lädt es künftig bei jedem Start.

Aktivieren

  1. Gib in Rhino den Befehl {command} ein. Das Aktivierungsfenster öffnet sich und zeigt deine Geräte-ID.
  2. Schick die Geräte-ID an {contact} – am einfachsten mit dem Knopf Request a code, der die Mail für dich vorbereitet.
  3. Du bekommst einen Aktivierungscode. Füge ihn unter „2)“ ein und klicke auf Activate.

Ein Testcode gilt bis zu einem festen Tag. Ab sieben Tagen vorher erinnert dich Rhino in der Befehlszeile daran. Einen neuen Code gibst du jederzeit mit dem Befehl {activationCommand} ein.

Aktualisieren

  1. Schließe Rhino.
  2. Ersetze die Dateien im Plugin-Ordner durch die neuen (die neue ZIP-Datei vorher wieder entsperren).
  3. Starte Rhino – die Aktivierung bleibt erhalten.

Neuer Rechner

Ein Aktivierungscode gehört zu einem Rechner. Auf einem neuen Rechner oder nach einer Neuinstallation von Windows zeigt das Aktivierungsfenster eine neue Geräte-ID. Schick sie an {contact}, dann bekommst du einen neuen Code.
